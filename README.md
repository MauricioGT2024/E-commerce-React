
# 🧩 E-commerce 🛒
¡Bienvenido al repositorio de mi proyecto de una tienda online 🚀    
Este proyecto está completamente funcional y representa una solución de e-commerce con frontend, backend forma parte de mi aprendizaje como desarrollador fullstack.

---
## ⚙️ Tecnologías utilizadas:

- Frontend: React, TypeScript, Tailwind CSS, Supabase (Auth, Storage)
- Backend: Nodejs, Expressjs, Supabase DB, Prisma
---

## ✅ Funcionalidades completadas:

- Autenticación de usuarios (registro, login).

- Visualización de productos dinámicos desde Supabase.

- CRUD completo de productos desde el panel de administración.

- Lógica de carrito de compras.

- Proceso de checkout simulado.
  
- Diseño responsivo y minimalista.

---




## 🔄 Revisión de entregable

Para revisar una entrega específica, cambia a la rama correspondiente:

1. Clonar el repositorio:

```bash
git clone https://github.com/MauricioGT2024/E-commerce-React.git
cd E-commerce-React
```


2. Iniciar el frontend y backend:
```bash
cd frontend
npm run dev

cd ../backend
npm run dev
```
3.Inicializar el proyecto (frontend y backend)
```bash
cd frontend
npm run dev

cd backend
npm run dev
```
